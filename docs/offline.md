# iPad 离线使用与飞行离线包

这份文档解决两件事：

1. **网站本体在飞行模式下能用**——PWA + Service Worker，装到主屏幕后不依赖网络；
2. **配套视频能离线看**——用哔哩哔哩官方 iPad App 的离线缓存，本站只负责顺序与检查清单。

线上地址：<https://nyatskr.github.io/ict-basic-software/>

---

## 1. 能力边界

| 内容 | 飞行模式下 | 说明 |
| --- | --- | --- |
| 课程、知识图谱、小节文字 | 可用 | 随外壳一起预缓存 |
| 103 道题、解析、错题与收藏 | 可用 | 题库在 `assets/js/data/bank.js` 里 |
| 10 个模拟实验 | 可用 | 状态机在本地跑，不需要后端 |
| 学习进度、视频准备标记 | 可用 | 存 `localStorage`，只在本机 |
| 云同步 | 排队 | 联网后自动补传，见 `docs/cloud-sync.md` |
| 外部文档、B 站网页 | 不可用 | 点链接会明确提示，不影响站内功能 |
| B 站视频 | 需提前缓存 | 用官方 App 缓存，本站不下载视频 |

预缓存总量约 **791 KB**（21 个文件），一次装好占用很小；视频才是占空间的部分。

## 2. 一次性安装（iPad）

1. 用 **Safari** 打开 <https://nyatskr.github.io/ict-basic-software/>，等首页出现。
2. 点地址栏右侧「共享」→「添加到主屏幕」，名称建议保留「基础软件」。
3. **从主屏幕图标启动**，确认没有地址栏（独立窗口）。
4. 打开侧栏「离线包」，看进度条下面那行状态：

   ```
   ● 离线缓存已就绪 · 版本 xxxxxxxxxxxx · 预缓存 21 个文件 · 当前在线 · 独立窗口运行
   ```

   出现版本号才算装好。显示「正在安装」就再等几秒；显示「尚未启用」说明不是 https 或用了无痕窗口。
5. 关掉 App 再打开一次，确认能正常启动。

> **存储是分开的**：主屏幕 App 和 Safari 标签页各有自己的 `localStorage`。
> 如果之前已经在 Safari 里做过题，先在「进度与数据」导出 JSON，装好后再导入一次。
> 反过来也一样：主屏幕 App 里的进度不会自动出现在 Safari 里。

## 3. 出发前：把 32 条视频缓存好

打开「离线包」页，从上往下就是学习顺序（域 → 专题 → 小节），不用管 B 站收藏夹自己的排序。

1. 点「**打开下一条未缓存**」：自动跳到对应行、高亮，并尝试唤起 B 站 App。
   没唤起就点那一行的「B 站」按钮；再不行点「网页」。
2. 在 App 里加入对应收藏夹（见下表），再点「缓存」，选 **720P**。
3. 回到本页勾「已缓存」。勾了「看完」会自动补上「已缓存」。
4. 想一次看全清单，点「**复制待缓存清单**」，粘到备忘录里照着做。
5. 出发前在飞行模式下实际播两条，能拖进度条才算缓存完整。

### 收藏夹划分

| 收藏夹 | 覆盖专题 | 视频数 |
| --- | --- | ---: |
| ICT-01 命令与权限 | oe-01 命令与文件、oe-02 用户、组与权限 | 16 |
| ICT-02 软件服务与进程 | oe-03 软件包与服务、oe-04 进程与内存 | 7 |
| ICT-03 存储与网络 | oe-05 存储与 LVM、oe-06 网络与防火墙 | 6 |
| ICT-04 Shell 与容器 | oe-07 Shell 脚本、oe-08 容器与 Intelligence | 3 |
| 合计 | | **32** |

32 条合计 **4 小时 59 分**。另有 3 条没有挂进任何小节（`v-perm-chmod`、`v-perm-octal`、`v-perm-suid`），
放在页面底部「可选补充」，不要求缓存。

### 收藏 ≠ 缓存

这两件事互相独立，容易混：

- **加入收藏夹**只是归类，方便以后找，**不会下载任何文件**；
- **缓存**才是把视频存到本机，要逐条点，还要选清晰度；
- 部分视频（付费、充电专属、版权限制）**没有缓存入口**，这属于平台限制。
  不要用第三方解析站绕过，也不要把 Cookie 或扫码登录凭据交给任何下载工具。

### 飞机上从哪里进

从 B 站 App 的「**离线缓存 / 下载管理**」进入播放。
从收藏夹或视频详情页点进去时，App 会先尝试联网拉取信息，飞行模式下可能转圈或报错。

## 4. 飞行模式验收清单

出门前逐条打勾，任何一条不过就别指望飞机上能补救。

- [ ] 1. 从主屏幕图标启动网站，不是从 Safari 标签页。
- [ ] 2. 打开飞行模式，同时关掉 Wi-Fi 与蓝牙。
- [ ] 3. 从后台彻底关掉 App，再重新启动：概览、课程、题库都能打开。
- [ ] 4. 进入任一小节，文字、题目、解析都在；做一道题。
- [ ] 5. 打开一个模拟实验，敲两条命令并判分；刷新后成绩还在。
- [ ] 6. 回到「离线包」：视频顺序、收藏与缓存标记都还在。
- [ ] 7. 在 B 站「离线缓存」里播放至少两条视频。
- [ ] 8. 关闭飞行模式联网，回「进度与数据」确认云同步恢复（未登录可跳过）。

第 8 条如果登录了 GitHub：断网期间的作答会在恢复网络后自动上传，不需要手动点。

全程不要做这些事：

- 用「文件」App 打开本地 `index.html`——相对资源、存储来源、Safari 限制都不可靠；
- 用第三方视频解析站下载 B 站视频——要交出账号凭据，也有版权风险；
- 把 Cookie、登录二维码、Token 交给任何「自动下载收藏夹」的工具或 AI。

## 5. 页面怎么用

路由 `#/offline`，侧栏「离线包」。

- **顶部**：正式视频总数、预计总时长、已缓存条数、剩余时长。
- **筛选**：全部 / 未处理 / 已收藏 / 已缓存 / 已看完，后面带实时计数。
- **每一行**：序号、标题、UP 主、时长、主资料或补充、所属小节，右侧三个标记 + B 站入口。
- **打开下一条未缓存**：按学习顺序找第一条没勾「已缓存」的，滚动高亮并唤起 App。
- **复制待缓存清单**：生成带序号、小节、时长、链接的纯文本，方便贴到备忘录。
- **重置标记**：连点两次确认，只清本页三个标记，不动做题记录。
- **可选补充**：3 条未挂进小节的视频，只提供入口，不参与统计。

标记存在 `localStorage` 的 `ict.flight.v1`，与学习进度（`ict.progress.v1.*`）分开：
它描述的是「这台设备准备到哪一步」，不参与云同步，换设备要重新勾。

## 6. 实现要点（维护者看）

```
manifest.json               应用名、图标、standalone、快捷方式
service-worker.js           由 tools/build-offline.py 生成，不要手改
assets/js/offline.js        注册 SW、更新提示、离线状态条、外链拦截
assets/js/flight-pack.js    飞行离线包的数据推导、标记与本页渲染
assets/icons/               由 tools/make-icons.py 生成（纯标准库，无 Pillow 依赖）
```

### 缓存策略

| 请求 | 策略 | 原因 |
| --- | --- | --- |
| 导航（打开 App） | 只给预缓存的 `index.html` | 保证外壳、脚本、数据是同一版 |
| 同源静态资源 | 缓存优先，未命中再走网络并回填 | 飞机上必须一次命中 |
| 跨域请求 | 不接管 | B 站、Supabase 保持原生行为，失败由页面提示 |

导航只从缓存取，是为了避免「新 `index.html` + 旧 `bank.js`」这种混用。
代价是新版本要用户点一下刷新——换来的是任何时刻打开都自洽。

### 版本与更新

- 缓存名 = `ict-basic-software-<内容哈希>`，哈希覆盖所有预缓存文件；
- 改任何一个资源，哈希就变，新 SW 装好但**不抢班**，页面右下角出现「有新版本 · 刷新」；
- 点刷新才 `skipWaiting`，激活时删掉所有旧缓存，然后整页重载；
- 不自动刷，是为了避免答题中途被打断（作答是即时落盘的，但体验上仍然突兀）。

改完资源记得重建：

```bash
python tools/build-offline.py     # 重新生成 service-worker.js
python tools/check-offline.py     # 静态校验：清单、图标、版本号
node tools/test-offline.mjs       # 运行时回归：断网后启动、答题、实验、外链提示
```

`tools/build-data.py` 写完 `assets/js/data/*.js` 后会自动调一次 `build-offline.py`，
所以改题库不会留下「数据变了、缓存版本没变」的坑。

### 云同步排队

`cloud.js` 在 `navigator.onLine === false` 时把同步状态标成 `offline` 并直接返回；
`online` 事件触发时自动 `syncNow()`。断网期间的作答照常写本机，不需要额外队列。

## 7. 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 加到主屏幕后仍显示地址栏 | 用的是「添加到书签」或旧版 iOS | 删掉图标，重新「添加到主屏幕」；确认 manifest 能访问 |
| 分享菜单里没有「添加到主屏幕」 | 无痕窗口 | 换普通窗口重开 |
| 打开是白屏 | 首次没联网成功，缓存没装上 | 联网打开一次，等状态行出现版本号 |
| 状态行一直「正在安装」 | 有资源 404 | 电脑上跑 `python tools/check-offline.py` |
| 断网后是新页面但样式错乱 | 旧缓存被手动清过一半 | 联网打开，等新版本提示后刷新 |
| 进度不见了 | 清过网站数据，或换了 Safari / 主屏幕 App | 用之前导出的 JSON 导入；以后定期导出 |
| B 站缓存列表为空 | 只加了收藏没点缓存，或缓存被清理 | 回「离线包」看哪些没勾「已缓存」 |

长期不用的网页 App 有可能被系统回收存储。重要进度建议出发前导出一次 JSON 放「文件」里。

## 8. 合规

- 视频只做链接跳转与顺序编排，不下载、不转存、不二次分发；
- 不提供绕过平台限制的下载方式，不代理登录凭据；
- 站点是个人备赛学习平台，题目为按公开考纲编写的预测练习，不是大赛官方真题。
